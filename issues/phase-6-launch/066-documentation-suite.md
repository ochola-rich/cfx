# [Phase 6] #066: Comprehensive Documentation Suite (Quickstart, Language Reference, Embed Guide)

**Phase:** Phase 6: Launch  
**Labels:** `phase:6-launch`, `documentation`, `guides`, `dx`  
**Milestone:** Phase 6: Launch  

---

## 1. Background & Context
For creators, designers, and site builders to adopt `cfx` without hesitation, documentation must be crisp, welcoming, example-rich, and free of programmer jargon. We need three core guides:
1. "Your First Piece in 2 Minutes" (fast onboarding tutorial)
2. Complete Visual Language Reference (every statement, keyword, and formula)
3. Embed Guide (instructions for HTML, Webflow, WordPress, Squarespace, React)

## 2. Objective
Author, edit, and publish the official documentation suite under `docs/user-guides/`.

## 3. Acceptance Criteria
- [ ] **"Your First Piece in 2 Minutes" (`docs/user-guides/quickstart.md`)**:
  - Step-by-step walkthrough creating a pulsing animated ring from scratch.
  - Interactive copy-paste examples.
  - Screenshots / GIF demonstrations of each step.
- [ ] **Complete Language Reference (`docs/user-guides/language-reference.md`)**:
  - Index of all shapes: `circle`, `rectangle`, `line`, `background`.
  - Index of all clauses: `at`, `radius`, `sized`, `colored`, `opacity`, `rotated`.
  - Math expressions and built-in variables (`time`, `mouse_x`, `mouse_y`, `width`, `height`).
  - Loops: `repeat ... times ... end`.
- [ ] **Embed Guide (`docs/user-guides/embed-guide.md`)**:
  - Plain HTML `<script>` tag guide.
  - CMS integration guides (Webflow custom embed code, WordPress HTML block, Notion embed, Squarespace code block).
  - Framework wrappers (React, Vue, Svelte snippet examples).

## 4. Definition of Done (DoD)
- [ ] All three guides reviewed, committed, and published.
- [ ] Readability tested with non-programmers for clarity and tone.
